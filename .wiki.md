# Project Summary

Casify est une boutique Shopify spécialisée dans les coques de protection pour smartphones. Le projet fournit un thème e-commerce complet et une page produit optimisée pour augmenter la conversion grâce à des offres multi-packs, des preuves sociales, des garanties, une présentation technique détaillée et un parcours d’achat connecté au panier réel Shopify.

# Project Module Description

- **Thème Shopify principal** : mise en page globale, en-tête, pied de page, recherche, panier, collections, pages de contenu, blog et politiques.
- **Pages produit classiques** : affichage standard des produits et variantes.
- **Page produit Convert** : modèle optionnel `product.convert.json`, à assigner aux produits nécessitant une présentation commerciale renforcée.
- **Buybox et variantes** :
  - Résolution des variantes réelles à partir des options produit.
  - Mise à jour dynamique du prix, du stock et des images.
  - Désactivation des combinaisons indisponibles.
  - Offres 1, 2 ou 3 coques avec remise et quantité réelles.
  - Ajout au panier via l’endpoint Shopify réel.
- **Value stack** : comparaisons de problèmes et solutions, grille d’avantages et graphique de résistance aux chocs.
- **Preuves sociales** : note moyenne, répartition des évaluations, statistiques animées, avis clients et bandeau presse.
- **Réassurance** : garanties, FAQ avec données structurées, conditions de retour et appel à l’action final.
- **Expérience interactive** : barre d’ajout au panier persistante, compte à rebours d’expédition, galerie interactive, animations au défilement et prise en charge de la réduction des animations.
- **Validation** : contrôles statiques des schémas Shopify, blocs, icônes, cibles JavaScript, couverture CSS et structure Liquid.

# Usage

## Installer et vérifier

Le projet est un thème Shopify natif. Aucun gestionnaire de dépendances ou build frontend spécifique n’est requis.

```bash
python3 audit_theme.py
python3 audit_theme2.py
python3 verify_cv.py
```

Les scripts vérifient notamment :

- la validité des documents JSON ;
- la correspondance entre templates et schemas ;
- l’existence des sections, snippets et assets ;
- les noms d’icônes ;
- les cibles JavaScript ;
- la couverture CSS ;
- l’équilibre des balises Liquid.

## Déployer le thème

1. Importer ou synchroniser le dossier `casify-theme` dans Shopify.
2. Vérifier les paramètres du thème dans l’éditeur Shopify.
3. Assigner le template `product.convert` aux produits concernés.
4. Contrôler les variantes, prix, stocks et images dans les données produit Shopify.
5. Effectuer une validation visuelle sur la boutique avant publication.

## Développer

- Modifier les sections Liquid dans `casify-theme/sections/`.
- Modifier les interactions dans `casify-theme/assets/`.
- Modifier les styles dans `casify-theme/assets/theme.css`.
- Modifier les paramètres dans `config/settings_schema.json`.
- Relancer les audits après toute modification de schema, template ou composant Convert.
