## The u1.2-fix change, read against regressions

- `motion` is now `let motion = false`, set true only inside
  `gsap.matchMedia().add('(prefers-reduced-motion: no-preference)', ..., root)`; the branch runs `entrance()` and
  `startRide()`, its cleanup sets `motion = false`, calls `stopRide()` and clears inline `transition: none`.
  `render(false)` and the `is-ready` swap run before the branch, so the readable static state does not depend on it.
- Every later motion use (`setName`, `setMoney`, the needmodel shake, the tick draw, the hint) still checks
  `motion`, so price and name write straight to text when reduced or after a live switch.
- `startRide()` tags rides with `rideGen`; `stopRide()` bumps it, so a ride resolving after cleanup or destroy
  destroys itself. `_cvcrDestroy` sets `destroyed`, reverts the matchMedia, then `stopRide()` and the cleanups.
- `els.chips` is an `Array.from(...)`, so `els.chips.concat(...)` in the cleanup is safe.
- The ride already required GSAP (`cvcrRide` returns null without it, js:114), so gating it behind
  `gsap.matchMedia` loses nothing when GSAP is missing.
- Pack "Change" scroll now reads `reduceQuery.matches` live.
- Fix probe (`harness/u1.2/fix/probe.json`): live reduce gives 0 ScrollTriggers, 0 canvas, stills visible, pause
  hidden, buy row shown; back on rebuilds 8 / 1; editor 4 cycles flat. Consistent with the code.
